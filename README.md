# CÉRÉBRON Ω — Farm 20 Data Knowledge

Mission: transformer des données et sources hétérogènes en connaissance traçable, dédupliquée, versionnée, vérifiable et réutilisable par les autres farms.

Règles:
- REALITY > COHERENCE
- CLAIM <= EVIDENCE
- SOURCE != CLAIM
- MEMORY != TRUTH
- DUPLICATE != INDEPENDENT EVIDENCE
- CORRELATION != CAUSATION
- PROVENANCE BEFORE FUSION
- CONTRADICTION MUST REMAIN VISIBLE UNTIL RESOLVED
- UNKNOWN REMAINS UNKNOWN
- VERIFY BEFORE COMMIT

La Farm 20 ne considère jamais une sortie IA comme vraie par défaut. Toute sortie externe reste candidate jusqu’à vérification, provenance et audit.
